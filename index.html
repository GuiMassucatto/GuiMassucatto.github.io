Destaque

Lanchonete Delivery

Projeto desenvolvido com HTML, CSS e JavaScript para simular o sistema de pedidos de uma lanchonete delivery. O sistema permite o cadastro, listagem e movimentação de pedidos entre diferentes estados (em execução, em entrega e finalizados), utilizando armazenamento local (localStorage). Possui interface responsiva, modal de confirmação e layout adaptado para desktop e mobile.

Catálogo de Produtos

Este projeto foi desenvolvido como parte de um desafio prático com foco na construção de uma interface web responsiva para exibição de produtos de vestuário e acessórios. A proposta consiste em apresentar os itens em dois formatos distintos (cards e lista), oferecendo uma experiência de navegação fluida e intuitiva ao usuário. As informações dos produtos são carregadas a partir de um arquivo JSON, e a aplicação utiliza HTML, CSS e JavaScript para alternar dinamicamente a visualização e garantir interatividade.

Guizap

Aplicação de chat em tempo real desenvolvida com Python e Flet, permitindo que múltiplos usuários conversem simultaneamente de diferentes dispositivos. O sistema identifica a entrada de novos participantes e transmite mensagens via pub/sub. O projeto é hospedado na web e possui interface interativa, responsiva e de fácil uso, simulando um mensageiro básico diretamente no navegador.
